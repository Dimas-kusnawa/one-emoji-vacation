A program that writes one emoji to `/output/entry.txt` (1 character, inside the 1–8 character gate): 🏝️. A desert island — palm, sand, sea, and nothing else on the calendar. No meetings, no Wi-Fi, no "one last thing": the dream vacation as a postcard you can read at a glance.

## Run it

```sh
python3 main.py
```
